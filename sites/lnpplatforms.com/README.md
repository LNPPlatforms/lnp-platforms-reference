# lnpplatforms.com

The LNP Platforms public site. Served by the app's own Pages project (lnp-platforms) through functions/_middleware.js and sites/hosts.js, no separate project. Custom domains on that project: lnpplatforms.com and www.lnpplatforms.com. Privacy, terms and data deletion redirect to app.lnpplatforms.com/legal. 404.html is the not found page.
