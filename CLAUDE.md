# Read PLANNING.md first

This is a reference copy of the CRM. Nothing here deploys. It is a PWA (web app that installs to the home screen), not a native app.

Follow PLANNING.md: interview the person, check the code for what already exists, write the spec, and if building, work on a `feature/...` branch (never `main`) and log every change in CHANGES.md so the owner can move it into the live app.
